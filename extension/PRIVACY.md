# Privacy Policy Summary

Visual AI Activity Tracker is designed for self-monitoring only. It is intended to help the installing user understand their own browsing activity on their own device.

## Data Collected Locally

- URL or hostname of the active page
- Page title and favicon metadata
- Session start and end timestamps
- Session duration and idle state
- Small screenshot thumbnails, if enabled
- Category and productivity score estimates
- Daily summaries and focus-mode blocked attempts

## Data Not Collected

- Keystrokes
- Clipboard contents
- Form input values
- Mouse movement trails
- Network request payloads
- Third-party telemetry or analytics identifiers

## Storage

- Primary storage is IndexedDB inside the extension.
- Optional cloud sync only happens if you explicitly enable it.
- API keys are stored locally in encrypted form.

## AI Usage

When AI features are enabled, the extension may send a screenshot thumbnail, URL, and title to the selected provider so it can generate category and insight suggestions.

## Your Controls

- Pause or resume tracking at any time
- Disable screenshots completely
- Export JSON or CSV data
- Delete old data or wipe everything
- Turn off cloud sync and AI at any time

## Incognito Behavior

Incognito tabs are never tracked. Tracking pauses automatically if an incognito tab becomes active.
