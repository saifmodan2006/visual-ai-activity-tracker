Privacy Policy & Guarantees

Visual AI Activity Tracker — 100% Local-First & Privacy-Focused

🛡️ Our Core Privacy Guarantee

Visual AI Activity Tracker is engineered strictly for personal self-monitoring. All activity tracking and data processing occur locally on your own computer inside your Chrome browser's sandboxed storage.

We do not run third-party tracking scripts, analytics SDKs, advertising networks, or background diagnostic reporting.

📥 Data Stored Locally On Your Device

  • LOCAL Active Webpage URLs & Titles: Logged only while tracking is enabled.
  • LOCAL Timestamps & Durations: Session start, end, active seconds, and idle state.
  • LOCAL Activity Categories & Scores: Inferred locally via domain & title pattern rules.
  • LOCAL Screenshots (Optional): Low-resolution compressed thumbnails stored in IndexedDB if screenshot capture is enabled.
  • LOCAL API Keys (Encrypted): Stored locally using AES-GCM 256-bit cryptography.

🚫 Data We NEVER Collect or Monitor

  • NEVER Keystrokes & Form Inputs: Never captured or inspected.
  • NEVER Passwords & Credit Cards: Automatic password field detection pauses screenshots.
  • NEVER Clipboard & Local Files: Never accessed or read.
  • NEVER Incognito Browsing: Incognito tabs are completely ignored and tracking automatically pauses.
  • NEVER Third-Party Telemetry: No external analytics services or ad pixels.

🤖 Optional AI Insights & Cloud Sync

AI Features: If you explicitly configure an OpenAI or Google Gemini API key, requests are transmitted directly from your browser to your provider's API. No intermediate proxy servers are used.

Cloud Sync: Cloud sync is disabled by default. If enabled, session metrics sync only to your configured server URL using your authorization credentials.

🎛️ Your Controls & Rights

  • Pause or resume activity tracking at any time using the extension icon or floating pill.
  • Turn off screenshot capture completely in Options.
  • Export all your data into CSV or JSON format at any time.
  • Delete specific session entries or wipe all stored local data with one click.
